# すうがく方眼ノート

中学1年〜高校3年の数学を、数学が苦手な人でも直感的に学べるブラウザ用の学習アプリです。
インストール不要で、PC・スマホのブラウザで動きます。

## できること

- 中1〜数Ⅲ・数C の 33 単元
- 各単元は 3 ステップ
  1. **イメージ** … ひとことで言うと何か、身近なたとえ、覚える式、つまずきポイント
  2. **さわってみる** … スライダーで動かせる図(天びん、さいころ実験、接線、積分の長方形など)
  3. **チャレンジ** … 毎回ランダムに作られる 4 択問題 5 問と解説
- レベル・XP・連続正解ボーナス・1日の目標・単元ごとの星3つ評価・スタンプ帳・ミックス10問
- 学習記録はブラウザの localStorage に保存(サーバーには送信しません)

## ファイル構成

```
index.html     公開用のページ(build.py で生成。直接編集しない)
build.py       src/ をまとめて index.html を作るスクリプト
src/
  shell.html   HTML の外枠(メタ情報・ファビコン)
  body.html    タイトル・フォント・CSS・画面の骨組み
  gen.js       単元の解説文と問題の自動生成
  labs.js      「さわってみる」の動く図
  app.js       画面遷移・クイズ・XP・スタンプ
.nojekyll      GitHub Pages で Jekyll 処理をしないための空ファイル
```

## 編集のしかた

```bash
# src/ のファイルを編集したら
python3 build.py      # index.html を作り直す
```

ローカルで確認するときは `index.html` をブラウザで開くだけで動きます。

## GitHub Pages での公開

1. このフォルダを GitHub リポジトリに push する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## 注意

- 単元の学年・科目の振り分けは、現行の学習指導要領(中学:2021年度〜、高校:2022年度入学生〜)の科目区分にもとづく目安です。教科書によって順番が異なる場合があります。
- フォントは Google Fonts から読み込みます(オフラインでは端末のフォントで表示されます)。
